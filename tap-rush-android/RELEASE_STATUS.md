# Tap Rush release-only work

Isolated QA Android wrapper for existing https://veenastudios.in/tap-rush/. The public game files and existing website remain unchanged.

## Limitations
- This is an ONLINE WebView prototype, not yet an approved offline package. The app needs internet to load the game. Verify whether an offline-bundled version is required before production.
- No ad SDK or production ads have been added; placement must be based on verified natural game breaks and compliant declarations.
- Application ID `in.veenastudios.taprush` is a PROVISIONAL candidate; verify before first Play upload.
- Workflow produces debug APK and UNSIGNED AAB only; not a Play-ready signed AAB.
- Must verify build workflow, game functionality, navigation, privacy URL, Data Safety, store listing, target audience, testing and Play Console account.
- No Play Console publication claimed.
