# समय का बंदी या नियति का? / Prisoner of Time or Destiny?

A three-part original novel by Varun Gupta.

- `chapters/`: numbered approved chapter PDFs (to be migrated after verifying all existing site links)
- `parts/`: compiled Part 1, Part 2, Part 3 PDFs when ready
- `complete-book/`: final full-length book PDF when approved
- `covers/`: cover artwork

**Current status:** The public website currently links to chapter PDFs at the repository root. Do not remove or rename those existing files until references are updated and verified. Creating this directory does not mean that chapter PDFs have already been copied here.
