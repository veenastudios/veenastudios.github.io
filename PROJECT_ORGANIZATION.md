## Website paths and migration policy
- Existing live URLs must not be broken.
- Published PDFs presently referenced at repository root must stay until page links are updated and verified.
- New book assets: assets/books/<project-slug>/
- New game assets: assets/games/<project-slug>/
- New social media assets: assets/social/<project-slug>/
- New design/app assets: assets/apps/<project-slug>/
- Large video masters, private files, contracts, account credentials and personal information do not belong in a public GitHub Pages repository.
- Do not claim a project is uploaded just because it appears in this index.
